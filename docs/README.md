# CinePulse — Документація

Повний документаційний пакет проєкту: від вимог до продакшн-експлуатації.

> **Весь менеджмент проєкту відбувається в [Notion](https://app.notion.com/p/40880c5f7ed58170bca1efda4e894ce9).** Цей каталог `docs/` — технічна документація до коду, а не трекер.

## Управління проєктом — Notion

Усе, що стосується планування й стану робіт, живе лише в Notion і в репо не дублюється:

| Що | Де в Notion |
|----|-------------|
| Роадмап, стан етапів, каталог сторінок | [Роадмап](https://app.notion.com/p/40880c5f7ed581f59f9fd2b85b8a8ebb) |
| Епіки (Now / Next / Later) | база «Епіки» на сторінці роадмапу |
| Задачі, пріоритети, статуси | база «Задачі» |
| Хронологія сесій і рішень | база «Журнал сесій» |
| Посилання, доступи, де лежать секрети | сторінка «Ресурси та доступи» |

Робочий цикл:

1. Задача береться з бази «Задачі» (представлення «Наступні кроки») і переводиться в *In Progress*.
2. Коміти — з номером задачі: `CIN-<номер>: <опис>` (номер = ID задачі в Notion).
3. Після завершення задача → *Done*; підсумок сесії — запис у «Журналі сесій».
4. Нове архітектурне рішення → ADR (у Notion і в [`03-architecture/decisions/`](./03-architecture/decisions/)).
